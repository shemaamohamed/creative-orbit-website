# Creative Orbit Marketing Co.

Bilingual (Arabic first, English) corporate site for Creative Orbit Marketing Co. The public profile and source assets live in `assets/`.

## Run locally

- `npm install`
- `npm run dev`
- Open `http://localhost:3000` (Arabic) or `/en` (English)

## Checks

- `npm run lint`
- `npm run typecheck`
- `npm run build`

## Contact behavior

Inquiry forms prepare a localized WhatsApp draft at `wa.me/966591777722`; visitors review and send the message themselves. Email and social URLs are not configured. The privacy page is a draft requiring company review before publication.

## Antigravity

Open this folder as the workspace in Antigravity. Workspace guidance is in `AGENTS.md`; the reusable engineering workflow is `.agents/skills/creative-orbit-engineering/SKILL.md`.
